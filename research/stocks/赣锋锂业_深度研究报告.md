## 四、基本面分析

### 4.1 主营业务结构

赣锋锂业是全球唯一实现"**锂矿-锂盐-锂电池-储能系统**"全产业链一体化布局的锂业巨头。

| 业务板块 | 主要产品 | 营收占比（估算）|
|---------|---------|--------------|
| 锂盐（上游）| 碳酸锂、氢氧化锂、氯化锂 | ~55% |
| 锂电池（中游）| 动力电池、储能电池、消费电池 | ~30% |
| 锂矿资源（自有）| 锂辉石（澳大利亚Mount Marion等）、盐湖（阿根廷Cauchari、南美等）| 支撑成本优势 |
| 固态电池（战略）| 固态/半固态电芯 | 快速放量中 |

### 4.2 核心竞争力

**① 全球最完整的锂资源布局**
- 澳大利亚 Mount Marion 锂辉石项目（持股50%，稳定供货）
- 阿根廷 Cauchari-Olaroz 盐湖（2025年爬坡中，规划产能4万吨/年碳酸锂）
- 非洲马里 Goulamina 锂矿（建设中）
- 国内宜春锂矿、云母矿（江西省重要资源）

**② 金属锂产能全球第一**
- 金属锂产能全球第一，是固态电池负极材料的唯一规模化供应商
- 固态电池核心材料（硫化物电解质、金属锂负极）自主可控

**③ 一体化协同优势**
- 上游自有矿+中游锂盐+下游电池+储能系统
- "锂超市"模式灵活调配全球资源
- 锂价下跌时上游可对冲，锂价上涨时全产业链受益

## 五、增长空间分析

### 5.1 锂价反弹空间

2025年碳酸锂价格走出**"V型反弹"**：

```
2025年初：~¥10万/吨（高位）
2025年中：~¥7万/吨（低点，供给过剩+需求低预期）
2025年底：~¥8-9万/吨（反弹，宜春矿证危机刺激）
2026年初：¥10万+/吨（持续反弹，较低点涨超200%）
```

**2026年供需格局展望：**
- 供给：新增约40-50万吨碳酸锂当量，总供给约208万吨
- 需求：预计约205万吨，供需接近紧平衡
- 结论：2026年锂价有望维持在**¥8-12万/吨**区间高位震荡，赣锋直接受益

### 5.2 固态电池——核心增长引擎

固态电池是赣锋最重要的战略看点：

| 时间节点 | 事件 |
|--------|------|
| 2021年 | 全球首次实现固态电池装车测试 |
| 2023年 | 国内最大固态电池生产基地建成投产 |
| 2024年12月 | 控股子公司赣锋锂电宣布大规模扩产计划 |
| **2026年** | 东莞基地全面投产，产能达**10GWh**（含半固态）|
| 2027年+ | 规划进一步扩产，固态电池营收CAGR预期超**80%** |

**技术突破：**
- 全球首发 **500Wh/kg 固态电池**（能量密度远超当前主流三元/磷酸铁锂）
- 双技术路线打通全产业链：硫化物电解质 + 金属锂负极
- 固态电池已明确产生业绩贡献，呈现快速增长态势

### 5.3 储能业务——新增长曲线

- 2026年通过南昌、东莞等基地投产，储能电池规划产能约**20GWh**
- 工信部将固态电池列为"十四五"重点攻关方向
- 2025年国内固态电池装车量同比暴涨**350%**至22万辆，赣锋深度受益

## 九、面临的问题与风险

### 9.1 主要风险

| 风险 | 详情 |
|------|------|
| **锂价波动** | 碳酸锂价格与股价高度相关，2024年锂价暴跌导致赣锋上市首亏。2026年供需紧平衡但价格仍可能大幅波动 |
| **资产减值压力** | 2025年计提减值¥5.87亿，主要因锂价下跌导致矿山资产估值下降 |
| **高负债/现金流压力** | 2020-2024年经营+投资现金流累计净流出约¥267亿，大规模扩产对资金链要求高 |
| **竞争加剧** | 天齐、Albemarle、SQM持续扩产，成熟锂盐产品竞争激烈 |
| **技术路线风险** | 全固态电池商业化时间表存在不确定性，若被钠离子电池等新技术替代可能削弱竞争力 |
| **地缘政治** | 海外锂矿（澳大利亚、非洲、南美）存在所在国政策变化风险 |

### 9.2 历史教训

- **2024年上市首亏**：碳酸锂价格从¥60万/吨（2022年峰值）暴跌至¥7万/吨，赣锋市值从3000亿跌至600亿
- **高资本开支双刃剑**：大规模扩产提升长期竞争力，但短期现金流压力大、借新还旧循环

### 核心结论

> **短期（1-3个月）**：锂价反弹趋势延续 + 固态电池消息催化，股价有望挑战¥82-85前高。H股较A 股折让明显（HK$73 vs ¥79.75），估值更有吸引力。
>
> **中期（6-12个月）**：10GWh固态电池/储能产能释放 + 锂价维持高位，2026年净利润有望达¥10-15亿，较2025年继续增长。核心变量：锂价能否维持在¥10万+。
>
> **长期（1-3年）**：固态电池若商业化成功（500Wh/kg量产），赣锋有望从"锂盐生产商"升级为"固态电池龙头"，估值体系有望重构。
>
> **最大风险**：锂价再次暴跌（若新能源车需求不及预期，或供给大规模释放）。
