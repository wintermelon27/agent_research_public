## 二、公司概况与商业模式

### 2.1 基本信息
| 项目 | 内容 |
|------|------|
| 公司名称 | Roblox Corporation |
| 交易所 | NYSE |
| 代码 | RBLX |
| 创立 | 2004年 |
| 上市 | 2021年3月（DPO） |
| 联合创始人 | David Baszucki（CEO）、Erik Cassel |
| 员工 | ~4,000+ |
| 业务 | UGC 游戏平台（元宇宙雏形） |

### 2.2 商业模式
Roblox 是一个 **用户生成内容（UGC）在线游戏平台**，核心逻辑：

1. **开发者端：** 创作者使用 Roblox Studio 制作 3D 游戏/体验
2. **玩家端：** 玩家免费加入，通过 Robux 虚拟货币消费
3. **平台端：** Roblox 抽取约 24.5% 作为平台收入
4. **递延收入：** 玩家购买 Robux 后，实际收入在玩家消耗时确认

**关键经济指标：**
- **DAU（日活跃用户）：** Q4 2025 = 1.44亿（+69% YoY）
- **用户时长：** Q4 2025 = 350亿小时（累计）
- **创作者分成：** 累计已向创作者支付 **$15亿+**
- **预订额（Bookings）：** 2026年全年指引 $82.8-85.5亿（+22-26% YoY）

### 2.3 收入确认的特殊性
Roblox 采用 "Bookings" 而非纯 GAAP 收入作为核心指标：
- **Bookings：** 玩家购买 Robux 的现金总额（不考虑消耗）
- **Revenue：** 在玩家消耗 Robux 时按比例确认
- **意义：** Bookings 是领先指标，提前反映用户付费意愿
